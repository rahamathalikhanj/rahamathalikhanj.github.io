PatternPulse: On-Device AI Technical Stock Pattern Screener

Deploying a 170MB+ computer vision neural network locally on desktop and mobile clients for zero-latency candlestick pattern detection.

Client / Ecosystem FinTech & Proprietary Trading Systems
Engineering Role Lead Architect & Machine Learning Systems Engineer
Platform Stack Flutter Desktop (macOS/Windows) & Mobile (iOS/Android)
Architecture Dart Isolates & ONNX Runtime Mobile

Project Overview

Technical chart analysis traditionally requires traders to spend hours manually inspecting candlestick charts for reversal and continuation patterns like Head & Shoulders, Double Bottoms, and Bull Flags. PatternPulse automated this workflow by deploying a trained deep convolutional neural network directly on user devices.

Engineering Challenges & Bottlenecks

  • Heavy Model Latency on Mobile: Executing a 174MB computer vision ONNX model on mobile chipsets without freezing the UI thread or running out of memory.
  • High-Frequency Tick Data Ingestion: Parsing and smoothing multi-year OHLCV candlestick time series data across thousands of financial symbols.
  • Variable Screen Resolutions: Ensuring consistent bounding box localization whether rendered on high-DPI desktop monitors or compact smartphone displays.

Architecture & Solutions

  • Background Dart Isolates: Offloaded ONNX inference, chart image normalization, and tensor transformations to dedicated background Dart Isolates, preserving a buttery-smooth 60 FPS UI.
  • Float16 Model Quantization: Optimized the neural network weights into quantized float16 representation, halving memory consumption without sacrificing pattern classification accuracy.
  • Custom Flutter Canvas Drawing Pipeline: Built a custom multi-layer painter rendering thousands of historical candles, volume bars, and moving averages on GPU-accelerated canvas.
  • Historical Backtesting Engine: Integrated quantitative backtesting logic calculating win-rates, stop-loss hit ratios, and risk-to-reward metrics for every detected formation.

Key Engineering Contributions

  • Designed and implemented the ONNX Runtime integration with Flutter via native C++ FFI bindings.
  • Engineered the multi-threaded Dart Isolate pipeline for non-blocking tensor processing.
  • Built interactive high-FPS candlestick rendering with pinch-to-zoom and crosshair measurement tools.
  • Architected the multi-timeframe symbol scanner capable of scanning 50+ tickers in under 3 seconds.
