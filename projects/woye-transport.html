Woye Transport: Resilient Urban Ride-Hailing for Emerging Markets

On-demand ride-hailing mobile application tailored for Ethiopia, featuring real-time driver tracking, fare calculation, and secure payments.

Client Woye Transport, Ethiopia
Role Senior Android Software Engineer
Platform Stack Native Java & Jetpack Compose
Architecture MVVM + Hilt DI + WebSockets

Project Overview

Woye Transport is an on-demand urban mobility application engineered to serve the rapid transit needs of passengers in Ethiopia. The platform allows riders to request nearby vehicles, receive transparent fare estimates before booking, and monitor their driver's live GPS route en route to pickup.

Deploying a high-frequency transit application in emerging African mobile markets requires special consideration for wide-ranging device hardware, high latency on cellular networks, and variable network bandwidth.

Business Problem & Challenges

  • Bandwidth Constraints & Cellular Fluctuation: Cellular data networks in urban corridors frequently oscillate between 3G and 4G, demanding compressed data payloads and aggressive request batching.
  • Diverse Android Hardware: The user demographic spanned diverse Android versions and memory configurations, necessitating a slim APK size and low memory consumption.
  • Real-Time Map Smoothness: Animating driver positions smoothly despite intermittent GPS telemetry packets without consuming excessive GPU cycles.
  • Localized Payment & Cash Reconciliation: Seamlessly accommodating cash payment confirmation flows alongside digital payment methods.

Technical Architecture & Engineering Solution

The application combined battle-tested core networking with modern Android UI tooling:

  • Hybrid Java & Compose Implementation: Maintained stable, low-overhead Java network and business modules while modernizing the user-facing booking screens using Jetpack Compose for fluid, reactive UI state transitions.
  • Modular Dependency Injection: Integrated Hilt (Dagger) to manage dependencies cleanly and enable targeted mocking during unit tests.
  • Optimized Socket Streaming: Built a resilient WebSocket driver tracking client that throttles GPS coordinate ingestion and uses quadratic bezier curve interpolation for silky-smooth vehicle movement.
  • Firebase Real-Time Messaging: Coupled FCM background triggers with local SQLite caching to preserve trip receipts and booking state across unexpected app terminations.

Key Contributions by Rahamath Alikhan

  • Modernized key booking and checkout screens to declarative Jetpack Compose UI while preserving foundational business logic.
  • Engineered the resilient WebSocket driver position consumer with packet deduplication and coordinate interpolation.
  • Implemented Hilt Dependency Injection across the application to increase testability and decouple network services.
  • Optimized APK size by 28% using ProGuard/R8 shrinking and WebP image assets, improving install conversion on bandwidth-limited networks.
