MotoSaaS: Automotive Dealership ERP & 3D Interactive Showroom

Building a multi-tenant dealership management SaaS with real 3D vehicle visualization, dual-mode customer/staff mobile workflows, and modular Clean Architecture.

Client / Ecosystem Two-Wheeler Dealerships & EV Retailers
Engineering Role Principal System Architect & Lead Engineer
Platform Stack ASP.NET Core 8 Web API & Flutter (iOS/Android/Web)
Architecture Clean Architecture CQRS & Riverpod

Project Overview

MotoSaaS was conceived to solve the massive fragmentation in automobile dealership operations—where sales CRM, service workshop job cards, spare parts inventory, and vehicle test rides were handled across disparate legacy tools. The goal was to build a clean, multi-tenant modular monolith supporting both web and mobile, headlined by an interactive 3D vehicle showroom.

Engineering Challenges & Bottlenecks

  • Strict Multi-Tenant Isolation: Enforcing strict tenant data boundaries across manufacturers, independent dealership organizations, and individual physical branches without database bloat.
  • Dual Persona Mobile Experience: Delivering a consumer-facing bike customizer and an authenticated employee staff portal within a single unified Flutter app without security leaks.
  • High-Fidelity 3D Rendering on Budget Smartphones: Rendering realistic 3D glTF models with real-time color shaders on low-end mobile devices without overheating or battery drain.

Architecture & Solutions

  • ASP.NET Core 8 Modular Monolith: Structured around Clean Architecture and CQRS, isolating bounded contexts (Identity, Catalog, Showroom, Service, Inventory) within a single, cost-effective deployable service.
  • Multi-Tier 3D Rendering Fallback: Built a flexible visualization pipeline that loads high-definition WebGL 3D models on capable devices while gracefully falling back to pre-rendered 360-degree image sets on low-RAM phones.
  • Dual-Experience Runtime Switching: Engineered strict runtime profile gating in Flutter, ensuring guests only see sales catalogs while dealership staff gain access to lead registers and job cards upon verified login.
  • PostgreSQL Tenant Query Filters: Configured global Entity Framework Core query filters enforcing tenant-id validation on every database query automatically.

Key Engineering Contributions

  • Authored the complete system architecture, API contracts, and database schema documentation.
  • Implemented the core ASP.NET Core 8 Web API with Docker containerization.
  • Engineered the Flutter 3D showroom integration and responsive tablet sales kiosk interface.
  • Constructed the multi-branch spare parts inventory and service workshop job card engine.
