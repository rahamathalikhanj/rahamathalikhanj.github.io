Ajman Taxi, Sixth Limo & Fytch Mobility Platform

Engineered multi-brand cross-platform mobility applications operating in Dubai and the UAE, serving thousands of daily passenger commutes with real-time WebSocket ride tracking and automated CI/CD release pipelines.

Client / Market Dubai Technologies, UAE
Role Lead Mobile Engineer
Platform Flutter Cross-Platform (iOS & Android)
State & Realtime BLoC + Riverpod + WebSockets

Executive Summary & Scope

Dubai Technologies, a prominent mobility and IoT solutions leader in the United Arab Emirates, operated separate transportation divisions: municipal taxi fleets (Ajman Taxi), luxury executive limousine services (Sixth Limo), and on-demand courier/dispatch networks (Fytch). The client required a unified, highly extensible mobile application platform that could run flawlessly across both iOS and Android while supporting white-label brand switching, distinct fare tariffs, and dynamic peak-time dispatch.

Operating in extreme road density conditions with stringent government telemetry reporting, the application required continuous bi-directional communication with dispatch servers, ultra-precise map navigation across UAE highway interchanges, and frictionless checkout via Stripe, PayPal, and Google Pay.

Cross-Platform Flutter Architecture

To maintain absolute parity between iOS and Android while enabling code reuse exceeding 85%, the solution was structured around a modular Flutter architecture combining BLoC for global workflow states and Riverpod for reactive dependency scoping:

  • BLoC State Management for Trip Lifecycles: The core booking and ride session states (Requesting, Dispatched, Arrived, In-Transit, Completed) were implemented as an event-driven Finite State Machine (FSM) using flutter_bloc. This prevented invalid state transitions and race conditions during intermittent 4G/5G handoffs.
  • Bidirectional WebSockets Stream: Implemented a resilient WebSocket client featuring exponential backoff reconnection and message queueing. Real-time telemetry frames from driver units update vehicle markers on the passenger map with sub-300ms latency.
  • White-Label Multi-Tenant Theming: Designed a centralized design token layer that dynamically injects branding assets, color palettes, and localization strings (Arabic RTL and English LTR) based on the target build flavor.

Key Technical Accomplishments

  • Dual Map Provider Integration: Interfaced with both Google Maps SDK and HERE Maps APIs, enabling intelligent fallback when map tile quotas or regional satellite data varied between Dubai, Sharjah, and Ajman.
  • Multi-Gateway Payment Orchestration: Implemented a unified payment abstraction layer wrapping Stripe Elements, PayPal Vault, and native Google Pay / Apple Pay tokens with automated localized VAT tax computation.
  • GitLab CI/CD Automated Build Pipeline: Configured automated GitLab CI runners to run linting, widget tests, generate iOS IPA and Android App Bundles (AAB), and auto-deploy staging builds to Firebase App Distribution and production builds to the Google Play Console.
  • Comprehensive Arabic RTL Localization: Architected complete Right-to-Left (RTL) layout mirroring, custom Arabic typography rendering, and culture-specific date/currency formatting across all user interaction touchpoints.

Production Deliverables & Impact

The platform delivered scalable performance across all targeted UAE mobility sectors:

  • Over 99.7% Telemetry Delivery Rate: Drivers and riders maintained continuous position awareness even across complex tunnel and highway transit corridors.
  • 40% Reduction in Release Overhead: Automated CI/CD pipelines cut new version deployment cycles from days to minutes.
  • Single Codebase Maintenance: Allowed a unified mobile engineering team to maintain iOS and Android applications with zero code duplication.
