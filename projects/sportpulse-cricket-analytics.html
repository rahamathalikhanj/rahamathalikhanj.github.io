SportPulse: Real-Time Cricket Telemetry & Match Analytics Engine

Delivering sub-second live match telemetry, custom canvas wagon wheels, and dynamic win probability calculations to cricket fans.

Client / Ecosystem Sports Analytics & Fantasy Gaming
Engineering Role Lead Client Software Engineer
Platform Stack Flutter (iOS, Android & Web Dashboard)
Architecture Reactive Streams & BLoC

Project Overview

SportPulse is an ultra-fast cricket intelligence and fan engagement platform. Designed to process and visualize rapid sports data feeds, the system renders live score updates, shot placement trajectory maps, run rate progress charts, and predictive win analytics in real time.

Engineering Challenges & Bottlenecks

  • High-Frequency Data Packet Bursting: During live IPL and international matches, tens of thousands of telemetry events occur simultaneously.
  • Complex Pitch & Shot Vector Drawing: Rendering wagon wheels and pitch heatmaps smoothly without GPU frame throttling.
  • Dynamic Win Probability Modeling: Calculating and updating win percentages after every ball based on shifting required run rates and wicket fall probabilities.

Architecture & Solutions

  • Persistent WebSocket Connection Pool: Built a fault-tolerant WebSocket streaming client in Flutter with instant failover to REST delta polling.
  • Custom Painted Vector Graphics: Utilized Flutter's CustomPainter API to render interactive pitch maps, wagon wheels, and worm graphs with zero third-party charting lag.
  • Algorithmic Win Predictor: Integrated mathematical scoring models calculating match win likelihood based on historical venue par scores, wickets in hand, and player strike rates.

Key Engineering Contributions

  • Engineered the live score streaming state machine in Flutter using reactive Dart streams.
  • Developed the custom Canvas vector graphics for field layouts and shot trajectory lines.
  • Optimized memory usage by disposing obsolete over telemetry packets during long-format matches.
