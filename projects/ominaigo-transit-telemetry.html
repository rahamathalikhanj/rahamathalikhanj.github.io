Project Overview

Ominaigo™ (GoLog) is a multi-tier enterprise transit, ride-hailing, and first-mile/last-mile delivery platform built to orchestrate thousands of active commercial vehicles simultaneously. Unlike conventional polling-based dispatch apps, Ominaigo combines a high-refresh-rate Flutter Driver Companion App, a TLS-secured MQTT QoS 1 IoT Ingestion Service, containerized C# .NET Core 8 Meta Worker Microservices, and a hardened PostgreSQL 16 database layer managing over 500 transactional stored procedures and functions.

Engineering Challenges & Bottlenecks

  • Sub-Second Telemetry Under Unstable Cellular Networks: Drivers operating across highway corridors, underground parking, and desert routes frequently drop signal, risking lost GPS breadcrumbs and stalled trip state transitions.
  • High-Frequency IoT Coordinate Ingestion: Handling thousands of concurrent vehicle location pings (lat/lon, speed, heading, accuracy) plus batched offline catch-ups without saturating relational database connections.
  • Strict Database Governance at Scale: Enforcing uniform transaction patterns, localization keys, and rollback safety across 514 PostgreSQL stored procedures and functions using Sqitch deploy/verify/revert pipelines.
  • Multi-Region & Multilingual Localization: Supporting English, Arabic (RTL), and regional GCC transit compliance across UAE, Saudi Arabia, Qatar, Kuwait, Oman, and Bahrain.

Architecture & Engineering Solutions

  • Flutter Driver App (ominaigo_driver_app): Architected with Riverpod 2.5 state management, Hive offline local caching, Easy Localization, Flutter DisplayMode for 120Hz fluidity, and resilient background GPS foreground services.
  • MQTT QoS 1 Telemetry Pipeline (IOTIngestorService): Implemented TLS-encrypted MQTT topic routing (vehicles/{vehicle_uno}/location, location_batch, status) with coordinate validation, UTC timestamp normalization, MongoDB high-write persistence, and guaranteed broker ACKs.
  • .NET Core 8 Meta Worker (ominaigo_meta_worker): Built Clean Architecture worker services (Domain, Application, Infrastructure, Automated Tests) running in lightweight Docker Alpine containers with automated Forgejo CI/CD promotion pipelines.
  • Sqitch-Governed PostgreSQL 16 Layer (ominaigo_database): Standardized 500+ database routines with deterministic deploy, verify, and revert scripts ensuring zero-downtime schema evolution.
