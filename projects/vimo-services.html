Vimo Services: Premium Chauffeur & Accessible Mobility Platform

High-reliability booking and live telemetry system for executive corporate transport and specialized wheelchair-accessible services in Singapore.

Client Domain Singapore Limousine & Medical Transport
Role Lead Android Software Engineer
Platform Stack Native Android (Kotlin & Jetpack Compose)
Architecture Clean Architecture + MVVM + Hilt

Project Overview

Vimo Services is an enterprise-grade mobile application designed to meet the strict demands of Singapore's executive transportation and specialized mobility sectors. It supports on-demand luxury chauffeur hailing, pre-scheduled corporate airport transfers, wedding charter arrangements, and certified wheelchair-accessible medical transport.

Given Singapore's exacting standards for transit reliability and stringent Electronic Road Pricing (ERP) gantries, the application required millimeter-accurate route plotting, automated geofence surcharge detection, and seamless zero-failure cashless billing.

Business Problem & Challenges

  • Precision Geofencing & Toll Calculations: Standard routing engines struggled with Singapore's complex CBD boundaries, airport surcharge zones, and time-based toll structures.
  • Critical Passenger Accessibility Needs: Wheelchair-accessible bookings required specific vehicle compatibility checks (hydraulic lift vs. ramp) and certified driver skill validation.
  • Strict Transaction Reliability: Corporate clients demanded frictionless corporate billing, tokenized credit card transactions, and instant automated digital tax invoices.
  • Real-Time Synchronization: Minimizing latency between customer dispatch requests and driver telematics to eliminate phantom bookings and reduce pickup wait times.

Technical Architecture & Engineering Solution

The application was built from the ground up using 3-Tier Clean Architecture to isolate UI components, business rules, and external data sources:

  • Presentation Layer: 100% declarative UI built with Jetpack Compose and Material 3 design tokens. State is managed reactively via Kotlin StateFlow and SharedFlow, ensuring zero UI flickers during intense coordinate streaming.
  • Domain Layer: Pure Kotlin business use cases (e.g., GetLiveRouteUseCase, CalculateGeofencedFareUseCase, ValidateAccessibilityRequirementsUseCase) with zero Android platform dependencies for complete unit test coverage.
  • Data Layer: Repository pattern combining Retrofit for REST API queries, Room DB for local offline caching of past rides and saved addresses, and HERE Maps Mobile SDK for high-precision turn-by-turn routing and polygon geofence checks.
  • Dependency Injection: Modular Hilt (Dagger) dependency injection scoping singletons to the application lifecycle and view-models to the navigation graph.
