Public Booking – Vimo Services Limousine App

Engineered a mission-critical chauffeur, corporate limousine, and wheelchair-accessible ride booking application with HERE Maps navigation, automated zone dispatch, and secure Stripe payment processing.

Client / Market Singapore Limousine Transport
Role Lead Native Android Engineer
Platform Native Android (Kotlin & Compose)
Architecture Clean Architecture + MVVM + Hilt

Executive Summary & Business Problem

Vimo Services is a premier transportation provider in Singapore offering corporate chauffeur transit, airport terminal meet-and-greets, luxury event charters, and specialized wheelchair-accessible vehicles. The client required a resilient, brand-tailored native Android application that could streamline on-demand and advance bookings while handling strict Singapore zone regulations, surge tariffs, and wheelchair logistics.

Previous iterations struggled with location drift inside tunnel passages, inconsistent payment settlement states, and sluggish UI re-renders on low-spec client devices. The mandate was to re-architect the application using modern Android engineering standards to achieve zero-crash reliability, silky 60fps UI performance, and instant driver-passenger telemetry sync.

Engineering Architecture & System Design

To satisfy stringent enterprise quality standards, the application was engineered using 3-Tier Clean Architecture with strict inversion of control. The business logic remains 100% agnostic of Android framework lifecycles:

  • Presentation Layer (Jetpack Compose & StateFlow): Built entirely with declarative UI components, custom theme tokens, and unidirectional state hoisting. ViewModels consume Use Cases and expose immutable StateFlow<UiState> streams, eliminating UI glitches and configuration change crashes.
  • Domain Layer (Pure Kotlin Use Cases): Self-contained use cases (e.g., CalculateSurgePriceUseCase, StreamLiveDriverLocationUseCase) encapsulate all business rules, accessibility surcharge formulas, and promo code verification without depending on external SDKs.
  • Data Layer (Repository Pattern + Room DB): A single source of truth orchestrating remote RESTful APIs via Retrofit/OkHttp, real-time push events via Firebase Cloud Messaging, and local offline persistence through Room DB with encrypted SharedPreferences.

Key Technical Accomplishments

  • HERE Maps SDK & Snapped Routing: Integrated HERE Maps Mobile SDK for high-accuracy urban vehicle rendering. Implemented vector tile caching and dead-reckoning map snapping to maintain fluid vehicle movement through Singapore's underground road expressways.
  • PCI DSS Compliant Stripe Gateway: Implemented end-to-end tokenized payment capture supporting credit/debit cards, Google Pay, and localized digital wallets. Handled 3D Secure 2.0 authentication flows seamlessly within Compose modals without external app redirection.
  • Wheelchair Vehicle Dispatch Logic: Developed specialized vehicle attribute matching algorithms that factor in ramp angle, passenger companion count, and electric wheelchair dimensions into vehicle category assignment.
  • FCM Real-Time Dispatch Pipeline: Configured high-priority Firebase push notifications paired with Android foreground services to ensure drivers and passengers receive instant trip acceptance and ETA alerts even in battery-saving sleep states.

Production Impact & Deliverables

The re-engineered Vimo Services application was deployed to the Google Play Store with notable production milestones:

  • 99.8% Crash-Free User Sessions: Achieved across thousands of rides in Singapore through defensive null-safety and robust exception boundaries.
  • Sub-Second Map UI Response: Reduced booking screen cold startup time to under 1.2 seconds using baseline profiles and Jetpack Compose compiler metrics.
  • Zero Payment Inconsistencies: 100% idempotent transaction state reconciliation using Room DB pending queue sync.
