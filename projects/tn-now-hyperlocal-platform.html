TN NOW: Real-Time Hyperlocal Discovery & Civic Media Platform

Building an ultra-responsive civic journalism and viral video streaming platform engineered to scale across all 38 districts of Tamil Nadu.

Client / Ecosystem TN NOW Media & Civic Network
Engineering Role Lead Backend & Mobile Systems Architect
Platform Stack Go Backend (Native ServeMux) & Flutter Client
Architecture Riverpod, GoRouter, Redis & pgx/v5

Project Overview

TN NOW was architected as a district-first civic discovery network designed to deliver hyper-targeted local news, civic alerts, municipal announcements, and viral video content to citizens across Tamil Nadu with zero algorithmic latency.

Engineering Challenges & Bottlenecks

  • Severe Traffic Surges During Breaking News: Handling 100,000+ simultaneous read requests during regional elections, weather alerts, and viral civic incidents.
  • Multilingual Full-Text Search: Supporting rapid phonetic and Tamil script full-text search across thousands of district stories without heavy Elasticsearch clusters.
  • API Abuse & Bot Scraping: Throttling malicious scrapers and click-farms without degrading performance for legitimate mobile app users.

Architecture & Solutions

  • Pure Go Native HTTP Engine: Engineered the entire API using Go 1.22's native http.ServeMux routing with zero external web framework overhead, achieving sub-10ms p99 latency.
  • PostgreSQL 16 tsvector Search: Implemented database-native full-text search using GIN indexing on tsvector columns, eliminating external search cluster hosting costs.
  • Redis 7 Sliding Window Rate Limiting: Deployed a Lua-scripted sliding window rate limiter in Redis 7, seamlessly filtering abusive IPs and safeguarding server resources.
  • Cloudflare R2 Object Storage: Distributed high-definition video reels and image assets over Cloudflare R2 with zero egress bandwidth fees.

Key Engineering Contributions

  • Designed and authored the full Go backend architecture using sqlc compiled type-safe queries.
  • Constructed the PostgreSQL 16 relational database schema with geofenced district partitions.
  • Built the Flutter client utilizing Material 3 design tokens, Riverpod state management, and Dio interceptors with automatic JWT rotation.
  • Configured Docker Compose containerization for rapid staging and one-click cloud deployment.
