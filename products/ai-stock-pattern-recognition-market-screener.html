Product Overview & Commercial Value

The AI Technical Stock Pattern Recognizer is an algorithmic market screener engineered for retail traders, proprietary trading desks, and fintech brokerages looking to automate technical analysis without manual charting fatigue.

Utilizing a trained 170MB+ convolutional neural network exported to ONNX format, the software executes local client-side computer vision inference on candlestick charts—identifying reversal and continuation structures in milliseconds with zero cloud computing costs.

Key Architectural Modules

1. Multi-Pattern Detection Engine

Instant classification of Head & Shoulders, Inverted Head & Shoulders, Double Tops, Double Bottoms, Symmetrical Triangles, and Bullish/Bearish Pennants.

2. On-Device ONNX Runtime Inference

Complete client-side evaluation with hardware-accelerated inference, ensuring complete privacy, zero subscription server latency, and offline accessibility.

3. Historical Backtesting & Accuracy Scoring

Automated historical win-rate calculation for each detected pattern across multi-year tick and OHLCV datasets.

4. Real-Time Alert Engine & Screener

Customizable multi-symbol scanning with audible triggers and instant push notifications when break-out formations complete.

Technical Specifications

Inference Architecture ONNX Runtime (Open Neural Network Exchange) with quantized float16 weights
Client Framework Flutter cross-platform supporting desktop window management and mobile viewports
Data Providers Yahoo Finance, Alpha Vantage, Polygon.io, and custom broker REST/WebSocket feeds
Chart Rendering High-FPS custom Canvas painting pipeline rendering 10,000+ candlesticks without frame drops
Offline Capability 100% functional offline for historical chart analysis and saved symbol watchlists
