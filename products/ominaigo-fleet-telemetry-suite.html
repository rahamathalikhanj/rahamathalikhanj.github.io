Ominaigo™ Enterprise Transit & MQTT Fleet Telemetry Suite

A mission-critical fleet dispatch, ride-hailing, and delivery telemetry platform uniting a high-refresh-rate Flutter Driver Companion App, TLS MQTT QoS 1 IoT ingestion, and .NET Core 8 microservice workers.

Platforms Supported iOS, Android, Linux Docker, Web

Product Overview & Enterprise Value

Ominaigo™ is engineered for municipal transport operators, logistics companies, and regional mobility startups across the United Arab Emirates (Dubai, Abu Dhabi, Sharjah, Ajman), Saudi Arabia (Riyadh, Jeddah, Dammam), Qatar (Doha), Kuwait, Oman (Muscat), Bahrain (Manama), Singapore, India, the UK, USA, Canada, and Australia.

Built on battle-tested MQTT QoS 1 telemetry ingestion and Clean Architecture .NET Core 8 background workers, Ominaigo guarantees zero lost vehicle breadcrumbs even across low-connectivity highways and underground transit zones.

Core Platform Modules

1. Flutter Driver Companion App

Riverpod 2.5 state management, Hive offline local storage, background foreground GPS service, shift & vehicle availability controls, and 120Hz high-refresh-rate UI.

2. MQTT IoT Ingestion Service

TLS-secured MQTT QoS 1 topics for single pings, offline batch uploads, vehicle status heartbeats, coordinate validation, and MongoDB high-write persistence.

3. .NET Core 8 Meta Worker

Containerized C# .NET 8 background microservices (Domain, Application, Infrastructure, Tests) handling dispatch events, webhooks, and enterprise ERP synchronization.

4. PostgreSQL 16 + Sqitch Core

Enterprise relational database with 500+ governed stored procedures, strict ACID fare reconciliation, and zero-downtime deploy/verify/revert migrations.

Technical Specifications

Mobile Framework Flutter 3.x (iOS & Android) with Riverpod 2.5, Hive offline DB & Easy Localization (RTL Arabic/English)
Telemetry Protocol MQTT over TLS (QoS 1) supporting single location, offline batch arrays, and ACK confirmations
Backend Microservices C# .NET Core 8 Worker Services (Clean Architecture, Docker Alpine, Forgejo / GitHub CI/CD)
Databases PostgreSQL 16 (Sqitch migrations & stored procedures) + MongoDB (high-throughput IoT ingestion)
Regional Readiness GCC (UAE, Saudi Arabia, Qatar, Kuwait, Oman, Bahrain), Singapore, India, Europe & North America
