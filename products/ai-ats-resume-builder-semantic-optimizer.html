Product Overview & Commercial Value

ResumeAI Pro is an enterprise-grade AI career technology platform designed for edtech bootcamps, university career centers, and SaaS entrepreneurs looking to offer automated resume tailoring and scoring.

Featuring a minimalist Stripe-inspired design built with React and TypeScript, the application connects to a resilient FastAPI backend that coordinates a Gemini API key rotation pool—ensuring uninterrupted high-volume LLM generation without rate-limit throttling.

Key Architectural Modules

1. AI Action-Verb Bullet Generator

Rewrites passive job descriptions into metric-driven, impact-oriented bullet points aligned with XYZ formula (Accomplished [X], as measured by [Y], by doing [Z]).

2. ATS Keyword Matcher & Scoring

Scans user resume against target job description and computes semantic match score, highlighting critical missing keywords and skills.

3. Resilient API Key Rotation Pool

Backend proxy pool that dynamically distributes Gemini LLM requests across multiple API keys with automated fallback and exponential backoff.

4. Clean ATS-Friendly PDF Export

Zero-clutter typography and structure engineered to pass major corporate ATS parsers (Workday, Taleo, Greenhouse, Lever).

Technical Specifications

Frontend Client React 18 SPA with TypeScript and clean custom CSS design system
Backend Service Python FastAPI microservice with asynchronous task workers
LLM Orchestration Google Gemini 1.5 Flash / Pro with round-robin key rotation and rate-limit guardrails
